# Documentación de Audit-ia

Índice maestro de la documentación de este repositorio. Cada historia que cierra suma su expediente y lo enlaza aquí; un documento sin índice es un documento perdido.

## Documentos

| Documento | Qué es |
|---|---|
| [README del repositorio](../README.md) | Presentación, capacidades con su estado, seguridad y uso del auditor web |
| [Este índice](README.md) | Índice maestro de la carpeta `docs/` |


## Cómo se mantiene esta carpeta

- Todo documento nuevo de diseño, instalación u operación se asienta en su subcarpeta temática (`arquitectura-y-diseno/`, `instalacion-y-despliegue/`, `operacion/`) y se enlaza desde este índice en el mismo commit.
- Disciplina de estado: **Construido** · **En desarrollo** · **Diseñado** · **Concepto** — los estados nunca se mezclan.
